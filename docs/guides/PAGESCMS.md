## PagesCMS

**Documentation:** https://pagescms.org/

## Connection

1. Make sure you have **read and write** permissions for the `aosmart.github.io` repository.
2. Go to https://app.pagescms.org/ and click **Sign in with GitHub**.
3. Select the **aosmart** organization, then open the **aosmart.github.io** repository.

## Usage

The panel on the left displays the different pages of the website.

<img width="317" height="372" alt="image" src="https://github.com/user-attachments/assets/30b972cc-5b06-4693-848a-db3a45d01fe4" />

By clicking on any page, you can view and edit its content. For example, in the element below, you can:

- Edit the text.
- Delete the element by clicking the **trash can** icon in the top-right corner.
- Change its position by dragging it using the **six dots** on the left.

<img width="951" height="297" alt="image" src="https://github.com/user-attachments/assets/56650f3f-9fe5-485d-9e0d-94fc88820101" />

At the bottom of each page, you can add new elements.

<img width="972" height="299" alt="image" src="https://github.com/user-attachments/assets/efa2db15-55fe-43a9-acf6-2784343c7b72" />

Don't forget to save your changes by clicking the **Save** button at the top of the page.

The **Media** section contains the images and files that can be used throughout the website.

<img width="315" height="93" alt="image" src="https://github.com/user-attachments/assets/6dc20ebc-fe01-4f27-bfd0-596fc6797795" />

You can upload new images or files here, but there is a **2–3 MB** size limit. For larger files, upload them directly to the repository:

https://github.com/aosmart/aosmart.github.io/tree/main/public

They will automatically appear in the **Media** section afterward.

In the **Configuration** tab, you can edit the `.pages.yml` file.
