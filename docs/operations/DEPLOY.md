## Deployment

To deploy the site, you need to:

1. Activate GitHub Actions.
   
<img width="1832" height="665" alt="image" src="https://github.com/user-attachments/assets/9c1ef69f-d941-4bf0-acd6-d1879f50d0f9" />

2. Set GitHub Actions as the source for GitHub Pages build and deployment.
   
<img width="1830" height="893" alt="image" src="https://github.com/user-attachments/assets/f88292a7-7809-43f9-a66d-2a92437ff901" />

3. Make the repository public.

You should then be able to visit the site at [https://aosmart.github.io/](https://aosmart.github.io/). It might take a few minutes for the site to be available. You can check the **Actions** tab of the repository to see if there were any problems.

Later on, you can buy a domain and search online for how to set up a custom domain with GitHub Pages.
