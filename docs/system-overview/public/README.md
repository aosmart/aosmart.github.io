The [`public/`](/home/javier/USherbrooke/stage/aosmart.github.io/public) folder contains static files served directly by the website without being processed by Astro.

| Folder | Purpose |
|---|---|
| [`fonts/`](/home/javier/USherbrooke/stage/aosmart.github.io/public/fonts) | Local Inter font files used by the site. |
| [`graphData/`](/home/javier/USherbrooke/stage/aosmart.github.io/public/graphData) | JSON sensor data used by the charts, plus a CSV table describing sensors. |
| [`images/`](/home/javier/USherbrooke/stage/aosmart.github.io/public/images) | Photographs organized by subject, including the forest, tower, sensors, team, and graphs. |
| [`logos/`](/home/javier/USherbrooke/stage/aosmart.github.io/public/logos) | Logos for project partners and funding organizations. |

Files retain the same URL structure. For example:

```text
public/images/foret/tower.jpg
```

is available on the website as:

```text
/images/foret/tower.jpg
```
