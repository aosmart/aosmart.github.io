## `ImageAndCaption.astro`

A component that displays an element with a caption below it. Contrary to the name, you can put almost any object with a caption.

For example, these two elements use `ImageAndCaption.astro`: one contains an image, while the other contains an embedded `Chart.astro` component.

## `FancyImageAndCaption.astro`

A component similar to the one above, but it allows users to click on images to view them in more detail. It is used in the `Galerie de photos` tab.
