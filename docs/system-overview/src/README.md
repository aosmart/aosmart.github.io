`src/` contains the main code of the application. It is divided in the following subfolders

| Folder | Description |
|---|---|
| [`src/components/`](https://github.com/aosmart/aosmart.github.io/tree/main/docs/system-overview/src/components) | Reusable Astro UI components shared across the site|
| [`src/content/`](https://github.com/aosmart/aosmart.github.io/tree/main/docs/system-overview/src/content) | Global site configuration. |
| [`src/layouts/`](https://github.com/aosmart/aosmart.github.io/tree/main/docs/system-overview/src/layouts) | Shared page layouts.  |
| [`src/newsposts/`](https://github.com/aosmart/aosmart.github.io/tree/main/docs/system-overview/src/newsposts) | Contains the content of the different articles appearing in `Nouvelles` |
| [`src/pages/`](https://github.com/aosmart/aosmart.github.io/tree/main/docs/system-overview/src/pages) | Main pages of the site.|
| [`src/pages/news/`](https://github.com/aosmart/aosmart.github.io/tree/main/docs/system-overview/src/news) | Dynamic routes for `Nouvelles` posts. |
| [`src/pagesMarkdown/`](https://github.com/aosmart/aosmart.github.io/tree/main/docs/system-overview/src/pagesMarkdown) | Structured Markdown content for the main site pages. Most content is stored as YAML sections in frontmatter and converted into UI elements by `Renderer.astro`. |
| [`src/styles/`](https://github.com/aosmart/aosmart.github.io/tree/main/docs/system-overview/src/styles) | CSS styling for the site |
