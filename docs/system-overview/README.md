This repository contains a static website built with the [Astro web framework](https://docs.astro.build/en/getting-started/). The site is also integrated with [Pages CMS](https://pagescms.org/docs/), allowing its content to be easily edited without writing HTML, CSS, or JavaScript.

Here you will find the main directories and files that make up the project.

## Root folders

| Folder | Description |
|---|---|
| [`.github/`](https://github.com/aosmart/aosmart.github.io/tree/main/docs/system-overview/github) | GitHub configuration, primarily the GitHub Actions workflow that builds and deploys the site to GitHub Pages. |
| [`public/`](https://github.com/aosmart/aosmart.github.io/tree/main/docs/system-overview/public) | Stores static assets such as images, documents, and JSON files. |
| [`src/`](https://github.com/aosmart/aosmart.github.io/tree/main/docs/system-overview/src) | Contains the main application code. |

## Root files

| File | Description |
|---|---|
| [`.pages.yml`](https://github.com/aosmart/aosmart.github.io/tree/main/docs/system-overview/pages.md) | Pages CMS configuration that defines how the site's content can be edited through the CMS. |
