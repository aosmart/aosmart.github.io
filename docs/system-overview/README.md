This repository contains a static website that was built using the [Astro web framework](https://docs.astro.build/en/getting-started/). The site also is also intregrate with the CMS [Pages CMS](https://pagescms.org/docs/) so that it can be easily edited without needing to write HTML code.

Here you will find the main directories and files important to this this project
## Root folders
| Folder | Description |
|---|---|
| [`.github/`]() | GitHub configuration, primarily the Actions workflow that builds and deploys the site to GitHub Pages. |
| [`public/`]() | Stores images, documents and JSON files |
| [`src/`]() | Main application source: Astro pages, components, layouts, styles, Markdown content, news posts, and site configuration. |

## Root files

| File | Description |
|---|---|
| [`.pages.yml`]() | Pages CMS configuration, that defines how content can be edited using the CMS |
